# Designer

The Designer is the visual editor for building ETL plans. It lets you assemble the steps of a plan without editing the YAML by hand.

A plan is a sequence of steps (select, insert, update, delete, join, sort, map, and more) executed in order. The Designer organizes plans on the left and shows the steps of the selected plan for editing on the right.

- **Add Plan** — create a new plan.
- **Select a plan** — inspect its steps and status.

::: warning ⚠️ NOTE
The Designer is currently under active development. For the full list of supported steps and their parameters, see [Configuration File Reference: plans](../config-yml#plans).
:::
