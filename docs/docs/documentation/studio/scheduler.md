# Scheduler

The Scheduler lets you manage cron-based schedules that trigger [plan](../config-yml#plans) executions. It corresponds to the `schedules` section of the [configuration file](../config-yml#schedules).

## Manage schedules

- **Add schedule** — create a new schedule and link it to a plan.
- **Edit** — update an existing schedule.
- **Delete** — remove a schedule.
- **Start / Stop** — enable or disable a schedule.

For the scheduling format and options, see [Configuration File Reference: schedules](../config-yml#schedules) and the [Scheduled ETL guide](../../guides/scheduled-etl).
