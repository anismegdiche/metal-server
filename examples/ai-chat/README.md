# Metal AI Chat Example

This example is a standalone Nuxt 4 application demonstrating how to connect to Metal's AI server API. It is separated from `apps/studio` so the Studio app can focus on ETL and MCP tooling.

## Run

1. `cd examples/ai-chat`
2. `yarn install`
3. `yarn dev`

By default, it expects the AI server at `http://localhost:3001`.
